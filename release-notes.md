# 1885 Start · v1.0.0-alpha

![1885 Start für Transport Fever 3](https://raw.githubusercontent.com/LordTheFirst/tf3-startjahr-1885/main/docs/images/banner.png)

**Neues freies Spiel ab 1885 – originale Fahrzeugdaten bleiben erhalten.**

## Download und Installation

1. **TF3_1885_Start_Windows_Komplett_1.0.0-alpha.zip** herunterladen und vollständig entpacken.
2. Die enthaltene **anleitung_de.pdf** lesen: Menüpatch anwenden, `start_year_1885` installieren und Revision 5 aktivieren.
3. Ein neues freies Spiel mit ausdrücklich ausgewähltem Jahr **1885** starten.

[PDF direkt ansehen](https://github.com/LordTheFirst/tf3-startjahr-1885/blob/main/docs/TF3_1885_Anleitung_DE.pdf) · [Ausführliche Anleitung](https://github.com/LordTheFirst/tf3-startjahr-1885#so-installierst-du-es)

GitHubs automatische „Source code“-Downloads sind nicht das Windows-Komplettpaket. Verwende die ausdrücklich benannte ZIP-Datei.

## Enthalten

- Windows-Menüpatch mit Versionsprüfung, Originalsicherung und Wiederherstellung; kein Python erforderlich.
- Begleitmod, Revision 5: private KI-Kutschen, frühe Depots, Wartung und Straßenterminals.
- Deutsche PDF sowie deutsche und englische Textanleitungen.

Kaufbare Fahrzeuge behalten ihre Originalwerte und Freigabejahre: kleine Güterkutsche ab **1885**, erste Personen-Droschke ab **1892**. Zum Abholen von Gütern ein Universal-Güterterminal verwenden; kleine Straßenhaltestellen entladen Güter.

**Alpha für Windows und die exakt geprüften Spieldateien aus Build 40423.** Offline geprüft; vollständiger Spieltest einschließlich Be-/Entladen, Wartung und Speichern/Laden noch offen. Separate Testspielstände verwenden. Keine bestätigte Spielstand- oder ModHub-Kompatibilität. Spielupdates können eine neu geprüfte Patchfassung erfordern.

## English

Start a new free game in **1885** using the Windows menu patch and companion mod, revision 5. Purchasable vehicles retain their original data and release years. Download the explicitly named complete ZIP, extract it, apply the menu patch, install `start_year_1885` and select 1885 for a new game. [English instructions](https://github.com/LordTheFirst/tf3-startjahr-1885/blob/main/docs/README_EN.md)

For the exact checked Windows game files from Build 40423. Offline checks passed; full in-game testing is pending. The first passenger carriage remains available from 1892. GitHub's automatic source archives are not the Windows complete package.
